Rubric: Advanced Features — Where to Implement

Feature (must do 3 of 4) Where How it delivers the insight
● Context-Aware Filtering Tab 1 — choropleth + KPI row When user selects a State, KPI callout text updates with state-specific numbers (e.g. "In WA, care gap is 0.99 — below national average of 1.13")
● Visual Tooltips / Modals Tab 1 — choropleth hover Hover SA3 → mini card showing care_gap_index, quality score, beds, pop_65_plus, state. Families can look up their suburb instantly.
● Narrative Scrollytelling All tabs — callout sequence Each tab ends with st.info / st.warning / st.error callouts that guide viewer from observation → implication → call to action.
● What-If Parameterization Tab 3 — pressure threshold slider Slider "Show SA3s where pressure exceeds X" → recount crisis zones in real time. Viewer sees how many communities enter crisis as threshold moves.
